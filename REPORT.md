# One-page Project Report — Math Workbench

## Purpose
Math Workbench demonstrates differentiated math learning by presenting one topic at three levels: Foundation, Standard, and Advanced.

## How it works
The browser displays prepared tasks, hints, and worked solutions for quadratic equations, the Pythagorean theorem, and derivatives. Learners can switch between levels, choose English or Russian, reveal hints/solutions, and copy a level. It runs entirely in the browser and does not require an API key or network call.

## Differentiation strategy
- **Foundation:** direct entry point and a short guided hint.
- **Standard:** a multi-step exercise using the same topic.
- **Advanced:** a transfer, modelling, or reasoning task.
- Hints are hidden initially so learners can attempt the problem first.

## Technology and privacy
Built with HTML, CSS, and JavaScript. The offline demo does not send learner input to an external AI service and requires no API key.

## Limitation and next step
This version uses prepared examples, not live AI-generated content. A future version could connect a server-side AI endpoint with protected credentials and appropriate availability/error handling.

## Evaluation plan
Ask learners to solve one task at each level, record completion and accuracy, and collect feedback about clarity and challenge.
