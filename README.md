# Math Workbench (Offline Demo)

A responsive educational web app demonstrating differentiation into Foundation, Standard, and Advanced math tasks.

## Run
Open `index.html` in a browser. No build step, server, Gemini API, or API key is required.

## Features
- Three difficulty levels with prepared examples, hints, and worked solutions
- Topics: quadratic equations, Pythagorean theorem, derivatives
- English and Russian interface/content
- Optional custom task field (custom task is displayed at Foundation level; its solution is not automatically computed)
- Copy current level

## Note
This version uses prepared examples rather than live AI generation. It is suitable as an offline prototype/demo; describe this honestly in any project report.
